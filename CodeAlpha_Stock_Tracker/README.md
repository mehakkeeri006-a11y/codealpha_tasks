# Task: Stock Portfolio Tracker

A Python application designed to help users manage their stock investments. It calculates the total value of a portfolio based on user inputs and real-time (or static) price data.

## 🚀 Features
- **Portfolio Management:** Add or remove stock symbols and quantities.
- **Value Calculation:** Automatically calculates total investment value.
- **Data Display:** Provides a clear summary of current holdings.

## 📦 Requirements
- Python 3.x
- Pandas (for data organization)
- Requests (if using real-time API)
