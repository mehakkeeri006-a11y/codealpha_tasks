# Task: Basic Chatbot

This project is a text-based chatbot that can simulate a conversation with a user. It uses basic Natural Language Processing (NLP) to understand user intent and provide relevant replies.

## 🚀 Features
- **Greeting Logic:** Recognizes standard greetings and farewells.
- **Pattern Matching:** Responds to specific queries based on keywords.
- **Interactive UI:** Simple console-based chat interface.

## 📦 Requirements
- Python 3.x
- NLTK (optional but recommended)
